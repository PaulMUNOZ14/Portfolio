# Paul MUNOZ - Portfolio

Portfolio personnel de **Paul MUNOZ**, étudiant en **BUT Informatique à Caen**.

Le site présente mon parcours, mes compétences, mes projets et différents moyens de me contacter.

Le portfolio est accessible ici :

### **[paulmunoz14.github.io/Portfolio](https://paulmunoz14.github.io/Portfolio/)**

## Contenu

Le site est organisé autour de trois parties principales :

* **Accueil** — présentation (très) rapide et identité du portfolio
* **Profil & Contact** — parcours, compétences et informations de contact
* **Projets** — présentation de plusieurs projets réalisés au cours de mes études et en dehors

Chaque projet dispose de quelques captures d'écran ainsi que d'un lien vers son dépôt GitHub.

## Technologies

Le portfolio a été réalisé avec des technologies web classiques :

* **HTML5** — structure du site
* **CSS3** — mise en page, animations et interface
* **JavaScript** — interactions et navigation entre les projets

Aucun framework n'est utilisé : le site repose uniquement sur **HTML, CSS et JavaScript**.

## Design

L'interface reprend volontairement certains codes visuels des environnements de développement :

* fenêtres façon IDE
* explorateur de fichiers
* onglets de fichiers
* syntaxe et commentaires de code
* interface sombre

L'objectif était de créer quelque chose qui corresponde à l'univers de l'informatique tout en restant simple à parcourir.
